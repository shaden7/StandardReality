# M1 — Free-form intentions (experimental)

The browser can now call a local Node.js LLM gateway. The model only **proposes** one action; a validator checks it and the deterministic world resolves it. No AI may write canonical state directly.

## Run without an LLM

```bash
npm install
npm test
npm run dev
```

Local parser handles basic movement, pickup/drop, generator controls, speech and waiting. With no backend running, the command UI attempts the gateway then falls back to the local parser.

## Run with an LLM

In a separate terminal, configure an API key **only for the local server** and start it:

**PowerShell**

```powershell
$env:OPENAI_API_KEY=[Environment]::GetEnvironmentVariable('OPENAI_API_KEY','Machine')
$env:OPENAI_MODEL='gpt-6-luna'
npm run dev:server
```

In another terminal:

```powershell
npm run dev
```

Open the URL shown by Vite. Browser requests to `/api/interpret` are proxied locally to `http://127.0.0.1:8787`. Do not put API keys into frontend code. The gateway uses an OpenAI-compatible chat completions API; other providers may need a different adapter.

## Try

- "Please walk north"
- "Pick up the metal mug"
- "Say the navigator is hiding something"
- Go into ENGINE and ask to switch off the generator, then click **Wait 5**.

The vocabulary of **mechanical effects remains intentionally small**. "I build a motorcycle" must be rejected or remain unrepresented, not falsely described as successful. Hearing speech does not yet produce NPC memory, belief changes, or social decisions. That is M2.

## Current limitations

- The backend calls a model once per command and does not yet report token consumption or costs.
- Only one primitive action per request; no complex composition, plans, or newly generated mechanics yet.
- Network errors fall back to the local parser; see feedback for the selected source.
- Model output is parsed as JSON, validated against allowed types and grounded item ids, then revalidated by the resolver.
- The API server is for **local development only**, not authenticated or production-hardened.
- Local browser snapshots from before M0 power systems may need a reset.
