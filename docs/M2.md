# M2 — Autonomous agents and causal observation

## Implemented

Three inhabitants share the player action resolver. Each tick updates local perception, then gives each agent at most one rule decision and one action. Perception records source and tick; heard statements become attributed memories and may create private beliefs. Speech never establishes the truth of a claim. Public work areas are a small piece of initial common knowledge used when an agent seeks a person without a recent sighting.

Mara observes generator status in workshop or engine areas, retrieves a spanner, walks to engine controls and invokes the same repair action available to the player. Ivo reacts to cooling he can observe and carries food away. Neri follows a routine exterior route until salvage enters local perception, then picks it up. A theft claim can lower trust and cause a later conversation when the accused is found. These are generic priorities and action primitives, not a fixed event sequence.

The browser has Start/Pause, three tick speeds, step controls, save/load, agent state, decision reasons and causal event references. Routine simulation and model requests run separately. At most one optional agent model request is in flight, with at least 30 seconds between requests. The server receives a subjective agent view and proposes one action. The browser validates proposal schema and target visibility; the canonical resolver enforces physical preconditions. Pausing or resetting discards stale agent responses. The API key remains server-side. Recorded model decisions include reason, latency and token count when supplied by the provider.

## Reproducible observations (seed 42)

- Idle, 30 ticks: Neri picked up salvage at tick 7.
- Player switches off generator from engine, then 16 ticks: Ivo picked up food at tick 2; Mara picked up the spanner at tick 3 and repaired the generator at tick 10. Samples spoiled at tick 5. Repair did not retroactively undo spoilage.
- Player says “Mara stole the food” near Ivo: Ivo heard the claim at tick 1 and spoke to Mara about it at tick 8. No theft event occurred.

These traces are deterministic rule runs. No live model call was made in these observations; any model decision in the browser is explicitly marked `llm`. A quiet or failed model request leaves rule simulation running.

## Boundaries and next experiment

The parser recognizes a small set of theft phrasings. Needs and relationships are shallow, and agents know static work areas. Vision is a Manhattan radius, not line-of-sight. The food and salvage behaviors are rule priorities, and the optional model currently suggests one primitive rather than a multi-step plan. Event and decision buffers are capped to prevent unbounded growth, which means old causal links can age out of a long session; snapshots preserve the retained window. A useful next experiment is comparing rule and model decisions on identical recorded subjective views, rated for novelty, coherence and causal validity, then expanding social beliefs beyond keyword claims.
